# "The pattern" Phrase Audit

42 occurrences of "the pattern" across 66 edited files. The phrase has become a structural tic — particularly in closing paragraphs, likely caused by the writer prompt instruction: *"Close by naming the pattern explicitly."*

**Suggested prompt fix:** Change the closing instruction to something like: *"Close by stating the claim plainly — without using the word 'pattern'."*

## Severity

- **High** — sentence-opening "The pattern is [not] X" formulations. Formulaic, repetitive, should be rewritten.
- **Medium** — "the pattern" used mid-sentence or as a reference ("confirm the pattern", "shows the pattern"). Less jarring but still frequent.
- **Low** — single occurrence, works in context.
